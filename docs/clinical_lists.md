# Стоматологические справочники (Расширенная версия)

В этом документе зафиксированы полные клинические справочники, которые будут использоваться как конфигурационный файл (config) для управления интерфейсом окна редактирования зуба.

## Глобальные статусы зуба (Tooth Presence Status)
1. `natural` — естественный зуб
2. `missing` — отсутствует давно / зона дефекта
3. `extracted_recent` — недавно удалён / лунка
4. `implant` — установлен имплант
5. `root_remnant` — остаток корня
6. `unerupted` — непрорезавшийся зуб
7. `impacted` — ретинированный / дистопированный
8. `primary` — молочный зуб
9. `supernumerary` — сверхкомплектный зуб

---
