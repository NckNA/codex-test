# Current Task: 001 - Создать базовый каркас приложения

## Цели
1. Инициализировать проект (React, TS, Vite, Tailwind).
2. Создать структуру папок (`src/components/layout`, `src/pages`, `src/types`, `src/data`).
3. Реализовать общий layout: левое боковое меню (Sidebar) и верхняя панель (Header).
4. Реализовать маршрутизацию между страницами.
5. Создать страницы-заглушки для всех разделов (Расписание, CRM, Приемы и т.д.).
6. Сверстать визуальный каркас страницы "Расписание" (мини-календарь, задачи, сетка времени 09:00 - 20:00, колонки врачей, демо-карточки).
7. Главная страница по умолчанию - "Расписание".

## Ограничения
- Не делать: backend, авторизацию, реальные SMS/WhatsApp, сложную карточку пациента, финансы, склад, отчеты, drag-and-drop, создание/редактирование записей.
- Сделать чистый, современный медицинский дизайн (сине-бело-серая гамма).

## Критерии приемки
- Проект запускается без ошибок (`npm run dev`).
- Левое меню отображается.
- Переключение страниц работает.
- По умолчанию открывается "Расписание".
- На странице расписания есть мини-календарь, задачи, дневная сетка, колонки врачей и демо-карточки записей.
- Отсутствуют упоминания MacDent.
- Создан отчет о выполнении.
