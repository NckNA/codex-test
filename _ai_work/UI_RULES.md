# Правила интерфейса (UI Rules)

Для сохранения единообразия системы DentalFlow CRM, при добавлении или изменении UI-компонентов ИИ должен следовать этим правилам:

1. **Единый стиль:** Использовать классы `Tailwind CSS`, применяя светлый фон (`bg-white`, `bg-slate-50`), серые границы (`border-slate-200`) и синий/серый/изумрудный цвета акцентов. Не добавлять "красивости" (сложные градиенты, тени), если они ухудшают чистоту медицинского рабочего процесса.
2. **Переиспользование действий:** Не плодить разные кнопки для одинаковых действий. Использовать стандартные иконки (из `lucide-react`) для редактирования (Edit2), удаления (Trash2), сохранения.
3. **Сохранность Layout:** Запрещено ломать общий макет страниц (Sidebar + Header + Content).
4. **Карточка пациента:** Не перегружать `PatientCardPage.tsx` лишним кодом. Если блок становится слишком большим, он должен быть вынесен в отдельную вкладку или компонент. Карточка должна оставаться читаемой.
5. **Разделение данных:** Важные медицинские данные (диагнозы, зубы) должны быть визуально отделены от финансовых (оплаты, балансы).
6. **Опасные действия:** Деструктивные действия (удаление пациента, плана, записи) должны требовать подтверждения (например, `window.confirm`).
7. **Бейджи статусов:** Статусы должны отображаться в виде понятных бейджей с цветовой кодировкой (например, красные для срочного/отмены, зеленые для завершенного/согласованного). Одинаковые статусы (например, "Завершен") должны выглядеть абсолютно одинаково в разных разделах приложения.
8. **Модальные окна:** Должны иметь единообразные кнопки "Отмена" (серая) и "Сохранить" (синяя), и крестик закрытия в правом верхнем углу.
