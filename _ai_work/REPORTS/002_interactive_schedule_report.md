# Отчет: Задача 002 - Интерактивное расписание

## Что сделано
1. **Обновление типов и данных**:
   - В `src/types/index.ts` добавлены подробные интерфейсы `Patient`, `Doctor`, `Appointment`, а также типы для статусов, источников и типов оплат.
   - В `src/data/seed.ts` добавлены вымышленные демо-данные: 8 врачей, 20 пациентов, и тестовые записи на текущий день (в том числе со статусом `blocked` для Обед/Операция).
2. **Локальное хранилище**:
   - Создан `src/utils/storage.ts` для управления состоянием в `localStorage` (init, get, add, update, delete).
   - Интегрирована автоматическая загрузка seed-данных при инициализации приложения (`main.tsx`).
3. **Глобальное состояние (Context)**:
   - Добавлен `ScheduleContext.tsx` для управления выбранной датой, режимом отображения (День/Неделя/Месяц) и фильтрами по врачу. Контекст обернут вокруг всего приложения в `Layout.tsx`.
4. **Улучшение Header**:
   - Добавлена возможность переключать фильтр врачей и режимы "День/Неделя/Месяц" через глобальный контекст.
5. **Модальное окно записи (`AppointmentModal.tsx`)**:
   - Реализована форма создания и редактирования записи.
   - Поля: пациент (выбор из списка), врач, услуга, кабинет, время начала/окончания, цена, источник, комментарий.
   - Добавлены быстрые статусы (Новая, Подтвержден, Пришел, В работе, Завершен, Не пришел, Отменен).
   - Встроена проверка конфликтов: блокируется сохранение, если у врача или в кабинете уже есть запись на это время (за исключением отмененных записей).
6. **Интерактивный экран расписания (`SchedulePage.tsx`)**:
   - Сетка времени разделена на шаги по 30 минут с 09:00 до 20:00.
   - Записи рендерятся динамически на основе `start` и `end`, позиционируясь абсолютно.
   - Клик по пустой ячейке сетки открывает модалку с предзаполненным временем и врачом.
   - Клик по существующей карточке открывает модалку редактирования.
   - Мини-календарь и кнопки `< >` управляют текущей выбранной датой.
   - Если выбран режим `Неделя` или `Месяц`, отображается заглушка ("Вид будет реализован позже...").

## Как проверить вручную
1. Открыть `http://localhost:5173`.
2. Убедиться, что расписание показывает текущий день и загружены демо-записи.
3. **Сценарий переключения даты**: Покликать по кнопкам `<` и `>` в левой панели, либо выбрать дату в input, убедиться, что записи фильтруются по выбранному дню.
4. **Сценарий создания**: Кликнуть на пустой слот (например, к "Смирнов А.В." на 12:00). В модалке выбрать пациента, услугу "Тест", и нажать "Сохранить". Карточка должна появиться в расписании.
5. **Сценарий редактирования**: Кликнуть по любой созданной карточке. Поменять статус (например, "В работе" -> сиреневый цвет), изменить цену. Нажать "Сохранить".
6. **Сценарий проверки конфликтов**: Попробовать создать новую запись поверх существующей. Должна появиться красная ошибка "Врач занят в это время" или "Кабинет занят в это время".
7. **Сценарий фильтрации**: В Header в выпадающем списке "Все врачи" выбрать одного врача. Расписание должно перестроиться и показать только его.
8. **Сценарий удаления**: Кликнуть по созданной записи и нажать "Удалить" (красная кнопка). Карточка должна исчезнуть.
9. **Перезагрузка страницы**: Обновить страницу браузера (F5) и убедиться, что созданные записи не пропали (сохранены в `localStorage`).

## Известные проблемы / Ограничения
- Режимы "Неделя" и "Месяц" показывают заглушку.
- Карточки пациентов (в модалке) выбираются только из демо-списка, создание "на лету" пока недоступно (по условиям задачи).
- Длительность записи вводится через выбор времени окончания, а не через select `Длительность: 1ч`.
