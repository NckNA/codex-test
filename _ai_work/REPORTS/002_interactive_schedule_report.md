# Отчет: Задача 002 - Интерактивное расписание

## Что сделано
1. **Обновление типов и данных**:
   - В `src/types/index.ts` добавлены подробные интерфейсы `Patient`, `Doctor`, `Appointment`, а также типы для статусов, источников и типов оплат.
   - В `src/data/seed.ts` добавлены вымышленные демо-данные: 8 врачей, 20 пациентов, и тестовые записи на текущий день (в том числе со статусом `blocked` для Обед, Операция, Не записывать, Личное время).
2. **Локальное хранилище**:
   - Создан `src/utils/storage.ts` для управления состоянием в `localStorage` (init, get, add, update, delete).
   - Интегрирована автоматическая загрузка seed-данных при инициализации приложения (`main.tsx`).
3. **Глобальное состояние (Context)**:
   - Добавлен `ScheduleContext.tsx` для управления выбранной датой, режимом отображения (День/Неделя/Месяц) и фильтрами (Врач, Статус, Источник). Контекст обернут вокруг всего приложения в `Layout.tsx`.
4. **Улучшение Header**:
   - Добавлены выпадающие списки (dropdown) для фильтрации записей по `Врачу`, `Статусу` и `Источнику`.
   - Режимы "День/Неделя/Месяц" управляются через контекст.
5. **Модальное окно записи (`AppointmentModal.tsx`)**:
   - Реализована форма создания и редактирования записи.
   - Поля: пациент (выбор из списка), врач, услуга, кабинет, время начала/окончания, цена, источник, комментарий.
   - Добавлены быстрые статусы (Новая, Подтвержден, Пришел, В работе, Завершен, Не пришел, Отменен).
   - Встроена проверка конфликтов: блокируется сохранение, если у врача или в кабинете уже есть запись на это время (за исключением отмененных записей). При редактировании запись не конфликтует сама с собой.
6. **Интерактивный экран расписания (`SchedulePage.tsx`)**:
   - Сетка времени разделена на шаги по 30 минут с 09:00 до 20:00.
   - Записи рендерятся динамически на основе `start` и `end`, позиционируясь абсолютно.
   - На карточке показывается пациент, услуга, время, статус, источник и цена.
   - Клик по пустой ячейке сетки открывает модалку с предзаполненным временем и врачом.
   - Клик по существующей карточке открывает модалку редактирования.
   - Записи фильтруются по выбранному дню, статусу, источнику и врачу.
   - Мини-календарь и кнопки `< >` управляют текущей выбранной датой.
   - Если выбран режим `Неделя` или `Месяц`, отображается заглушка ("Вид будет реализован позже...").

### Известные проблемы / Ограничения
- Режимы "Неделя" и "Месяц" показывают заглушку (ожидается в будущих задачах).
- Длительность записи вводится через нативный date/time picker (start/end), а не через dropdown выбора длительности (в текущих рамках этого достаточно).
- В карточке записи `source` может не умещаться, если окно слишком узкое (реализован базовый UI с opacity).
- Отсутствуют ошибки в консоли браузера и при билде `npm run build`.
