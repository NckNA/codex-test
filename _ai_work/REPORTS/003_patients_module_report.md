# Отчет: Задача 003 - Модуль пациентов

## Что сделано
1. **Обновление типов и хранилища**:
   - Интерфейс `Patient` дополнен полями `allergies`, `balance`, `bonusBalance`.
   - В утилиту `src/utils/storage.ts` добавлены методы `savePatients`, `addPatient` и `updatePatient` для обеспечения сохранения данных о пациентах в `localStorage`.
2. **Модальное окно пациента (`PatientModal.tsx`)**:
   - Создан переиспользуемый компонент `PatientModal` для добавления новых и редактирования существующих пациентов.
   - Реализована валидация обязательных полей (`fullName` и `phone`) с отображением ошибки.
   - Включает поля: ФИО, Телефон, Дата рождения, Источник, Статус, Аллергии, Баланс, Бонусный баланс, Заметки.
3. **Страница списка пациентов (`PatientsPage.tsx`)**:
   - Сверстана страница со списком всех пациентов в виде таблицы.
   - Добавлен поиск (по имени и телефону) и фильтры по `status` и `source`.
   - Интегрирована модалка `PatientModal` (создание и редактирование из списка).
   - Вычисляются даты последнего и следующего визита на основе истории приёмов `appointments`.
   - Добавлены кнопки "Открыть" (переход в карточку) и "Редактировать".
4. **Карточка пациента (`PatientCardPage.tsx`)**:
   - Создана страница карточки пациента с маршрутом `/patients/:patientId`.
   - Внедрена структура с табами (Обзор, История приёмов, План лечения, Финансы, Документы, Коммуникации, Файлы).
   - **Таб "Обзор"**: отображает все детали профиля пациента, балансы, визиты и имеет кнопку "Редактировать".
   - **Таб "История приёмов"**: отображает список приёмов пациента (на базе существующих данных `appointments` в `localStorage`), отсортированный по убыванию (сначала новые).
   - Для остальных табов реализованы чистые заглушки "В разработке".
5. **Связь с расписанием (`AppointmentModal.tsx`)**:
   - В модальном окне редактирования существующей записи добавлена кнопка-ссылка "Карточка пациента", перенаправляющая на маршрут `/patients/:patientId`. Существующая логика приёмов и расписания из Задачи 002 не сломана.

## Как проверить вручную
1. Открыть `http://localhost:5173`.
2. В левом меню перейти в раздел "Пациенты".
3. **Список пациентов**: Убедиться, что демо-пациенты загрузились. Проверить поиск (ввести часть имени или телефона). Проверить фильтры по статусу и источнику.
4. **Создание пациента**: Нажать "Добавить пациента", попробовать сохранить с пустым именем - получить ошибку. Заполнить данные, сохранить, убедиться, что он появился в списке.
5. **Редактирование из списка**: Навести на строку пациента, нажать "Редактировать", изменить данные и сохранить.
6. **Карточка пациента**: Нажать "Открыть" у любого пациента. Вы перейдете в профиль пациента. На вкладке "Обзор" должны быть актуальные данные. На вкладке "История приёмов" – список его приёмов (если они есть).
7. **Переход из расписания**: Перейти в "Расписание", кликнуть на любую созданную запись (например, на "Борисов Б.Б."). В открывшейся модалке рядом с заголовком "Редактирование записи" нажать на кнопку "Карточка пациента" – откроется профиль пациента.

## Известные проблемы / Ограничения
- Вкладки карточки пациента (План лечения, Финансы, Документы и др.) являются заглушками.
- Связь "Последний/Следующий визит" при редактировании времени приёма из расписания может требовать обновления страницы списка пациентов для пересчета, если открыты соседние окна (в рамках одного окна пересчет происходит автоматически при ререндере).
- При создании приёма из расписания всё ещё нельзя на лету создать нового пациента (оставлено в соответствии с требованиями Задачи 002).
