# Текущая архитектура (Architecture Current)

Документ описывает фактическое текущее состояние проекта по коду.

## 1. Маршруты приложения и страницы
Реализация через `react-router-dom` в `src/main.tsx`. Все страницы обернуты в `<Layout />`.

- **Реализованные страницы**: `SchedulePage.tsx`, `PatientsPage.tsx`, `PatientCardPage.tsx`.
- **Страницы-заглушки**: `AppointmentsPage.tsx`, `BonusPage.tsx`, `CrmPage.tsx`, `DoctorsPage.tsx`, `DocumentsPage.tsx`, `FinancePage.tsx`, `MailingPage.tsx`, `MedicalPage.tsx`, `ReportsPage.tsx`, `SettingsPage.tsx`, `SmsPage.tsx`, `StatisticsPage.tsx`, `WarehousePage.tsx`.

**Уровень уверенности**: Высокий.

## 2. Layout
Находится в `src/components/layout/`.
Отвечает за боковое меню (`Sidebar.tsx`) и верхнюю панель приложения (`Header.tsx`).
Использует иконки из `lucide-react`.

**Уровень уверенности**: Высокий.

## 3. Контекст расписания
Находится в `src/context/ScheduleContext.tsx` и `src/context/ScheduleProvider.tsx`.
Управляет глобальным состоянием выбранной даты в календаре, открытием/закрытием `AppointmentModal`, и логикой drag-and-drop. Отвечает за доступ компонентов сетки к методам хранилища.

**Риск**: Сильная связь логики интерфейса с состоянием.
**Уровень уверенности**: Высокий.

## 4. Storage
Находится в `src/utils/storage.ts`.
Реализует паттерн псевдо-бэкенда. Полностью синхронная работа с `localStorage`.
Модуль содержит:
- Инициализацию демо-данных из `src/data/seed.ts` (при отсутствии флага `df_initialized`).
- CRUD-функции для пациентов, врачей, записей, зубных карт, планов лечения, основной жалобы и клинических находок.

**Риск**: Синхронность может усложнить переход на реальный бэкенд в будущем. Хранилище чувствительно к ошибкам структуры (нет авто-миграции типов).
**Уровень уверенности**: Высокий.

## 5. Типы
`src/types/index.ts`. Описывает интерфейсы всех бизнес-объектов CRM.
Ключевые интерфейсы: `Patient`, `Appointment`, `Doctor`, `DentalChart`, `ToothRecord`, `TreatmentPlan`, `ChiefComplaint`, `DentalFinding`.

**Уровень уверенности**: Высокий.

## 6. Компоненты пациентов
- `PatientModal.tsx`: Отвечает за создание и редактирование информации пациента. Содержит базовые поля и сохраняет данные в Storage.

**Уровень уверенности**: Высокий.

## 7. Компоненты зубной карты
- `DentalChartTab.tsx`: Собирает карту и диагноз.
- `ToothGrid.tsx`: Визуальное отображение челюстей 18-28 и 48-38.
- `ToothEditorModal.tsx`: Открывается при клике на зуб, позволяет сменить его статус и добавить заметки.

**Уровень уверенности**: Высокий.

## 8. Компоненты проблем и рисков
- `FindingsRisksTab.tsx`: Таб в профиле пациента, агрегирующий основную жалобу и списки найденных рисков/проблем.
- `FindingModal.tsx`: Модальное окно для создания сущности находки, включающее выбор статуса, степени риска и зуба.

**Уровень уверенности**: Высокий.

## 9. Компоненты планов лечения
- `TreatmentPlansTab.tsx`: Выводит список планов лечения.
- `TreatmentPlanModal.tsx`: Позволяет собирать этапы лечения (Treatment Stages), задавать цену и статус.

**Уровень уверенности**: Высокий.

## 10. Рискованные зоны (Risky Areas)
- **`PatientCardPage.tsx`**: Агрегирует большое количество данных (`useMemo` для `dentalSummary`) и может стать "God Component".
- **Хрупкость Storage**: При изменении типов в `index.ts` старые данные в localStorage пользователя сломаются без механизма миграции.
