# DentalFlow CRM - Product Spec

## Описание
DentalFlow CRM — прототип веб-приложения (CRM/МИС) для стоматологической клиники.
Продукт предназначен для управления расписанием, пациентами, врачами, приемами, документами и финансами.

## Технологический стек
- Frontend: React, TypeScript, Vite
- Стилизация: Tailwind CSS
- Маршрутизация: react-router-dom
- Иконки: lucide-react

## Ограничения
- Не копировать MacDent.
- Не использовать логотип, бренд, точный дизайн, фирменные элементы.
- Не использовать реальные данные пациентов (только демо-данные).
